### Um pouco sobre mim 

Sou estudante de **Análise e Desenvolvimento de Sistemas** no **SENAI Techs**.

Tenho foco em **Java, Flutter, Linux, Arquitetura de Redes, IoT e Requisitos**. Gosto de compreender a fundo os requisitos e a arquitetura das soluções para transformar problemas em sistemas eficientes e bem estruturados.

**Atualmente o meu foco principal está em:**
* ☕ Desenvolvimento de aplicações com Java
* 📱 Desenvolvimento mobile com Flutter
* 🐧 Ambientes e sistemas Linux
* 🌐 Arquitetura de Redes e Internet das Coisas (IoT)
* 📋 Levantamento e gestão de Requisitos de Software
